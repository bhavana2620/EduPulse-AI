# EduPulse-AI
EduPulse AI – Intelligent Student Success Platform with AI-powered career guidance, ATS resume optimization, mock interviews, academic tracking, and placement management.
EduPulse AI is an AI-powered student success platform that helps students improve their academic performance, placement readiness, and career development. The platform combines AI-based career guidance, mock interviews, study planning, resume optimization, and placement tracking in a single application.

It provides features such as an AI Student Twin for performance analysis, Voice AI Mock Interviews for interview practice, an AI Career Mentor for personalized guidance, and an ATS Resume Builder to create professional resumes. Students can also track internships, certifications, goals, and academic progress through interactive dashboards.

The project is developed using HTML, CSS, JavaScript, Chart.js, Google Gemini AI, and Web Speech API to create a modern, responsive, and user-friendly experience.

Objective:
To help students enhance their skills, prepare for placements, and achieve their career goals through AI-powered guidance and analytics.

Technologies Used:
HTML5, CSS3, JavaScript, Chart.js, Google Gemini AI, Web Speech API, Local Storage.
